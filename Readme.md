# Interview Questions & Answers 🚀

A collection of interview questions, answers, and learning notes covering different topics in software development, web development, and computer science.

## 📚 Topics Covered

- **HTML & CSS** – Fundamentals, concepts, and common interview questions.
- **JavaScript** – Core concepts, ES6+, asynchronous programming, and more.
- **React.js** – Components, Hooks, State Management, and performance.
- **Next.js** – App Router, Server Components, Rendering, Caching, and Runtime.
- **Node.js & Express.js** – Backend fundamentals, APIs, Middleware, and Authentication.
- **Databases** – MongoDB, Mongoose, SQL, and database concepts.
- **Computer Science** – Networking, HTTP/HTTPS, Operating Systems, and general concepts.
- **UI/UX Design** – User Persona, Wireframes, User-Centered Design, and CRAP principles.

## 🎯 Purpose

The goal of this repository is to:

- Prepare for technical interviews.
- Strengthen fundamental programming concepts.
- Provide clear and simple explanations.
- Collect useful questions and answers in one place.
- Help developers revise and improve their technical knowledge.
