# Interview Questions & Answers 🚀

A collection of technical interview questions, answers, and learning notes covering software development, web development, computer science, and programming fundamentals.

## 📚 Topics Covered

### Frontend Development
- **HTML** – Fundamentals, semantic elements, forms, and accessibility.
- **CSS** – Selectors, Flexbox, Grid, Responsive Design, and animations.
- **JavaScript** – Core concepts, ES6+, asynchronous programming, and more.
- **React.js** – Components, Hooks, State Management, and performance.
- **Next.js** – App Router, Server Components, Rendering, Caching, and Runtime.

### Backend Development
- **Node.js** – Runtime, Event Loop, Modules, and asynchronous programming.
- **Express.js** – REST APIs, Middleware, Routing, and Authentication.
- **Laravel** – PHP framework fundamentals, Routing, Controllers, Models, Eloquent ORM, Middleware, and Authentication.

### Programming & Computer Science Fundamentals
- **OOP** – Classes, Objects, Inheritance, Encapsulation, Abstraction, and Polymorphism.
- **Data Structures & Algorithms** – Basic data structures and problem-solving concepts.
- **Computer Science** – Networking, HTTP/HTTPS, and Operating Systems.
- **Linux Basics** – Terminal commands, File System, Permissions, Users, Processes, and Package Management.

### Databases
- **Database Fundamentals** – Tables, Relationships, Primary Keys, Foreign Keys, and Normalization.
- **SQL** – Queries, Joins, Indexes, and Transactions.
- **MongoDB** – NoSQL concepts, CRUD Operations, Aggregation, and Indexing.
- **Mongoose** – Schemas, Models, Validation, and Relationships.

### UI/UX Design
- **UI/UX Fundamentals** – User Persona, Wireframes, User-Centered Design, Usability, Accessibility, and CRAP principles.

## 🎯 Purpose

The goal of this repository is to:

- Prepare for technical interviews.
- Strengthen programming and computer science fundamentals.
- Provide clear and simple explanations.
- Collect useful questions and answers in one place.
- Help developers revise and improve their technical knowledge.
